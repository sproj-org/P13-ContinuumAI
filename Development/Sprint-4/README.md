# Sprint 4 Update

Sprint 4 focused on strengthening the product for real-world organizational usage. The primary goals were to improve existing features, introduce a strategy layer, and significantly enhance UI/UX quality across the platform.

## Sprint Goals

- Improve usability and visual consistency.
- Add enterprise-ready access control and administration.
- Upgrade the analytics experience with richer visual interactions.
- Introduce strategic monitoring through KPI-driven evaluation.
- Improve overall product maturity for final delivery.

## Key Deliverables

### 1. Theme Conversion (Dark to Light)

The application theme was redesigned from dark mode to light mode to better align with our target product experience. This improved readability, made the interface feel more professional, and better suited extended analytics workflows.

### 2. Admin Panel Added and Public Sign-Up Removed

We introduced a full admin workflow and removed open public sign-up.

- The platform is intended for closed organizational environments.
- Admins can now create organizations, upload datasets, and onboard members.
- Only authorized members can access assigned datasets and workspace features.

This change established controlled access and made the system more secure and deployment-ready.

### 3. Visualization Engine Migration (Plotly to AntV)

All visualizations were migrated from Plotly to AntV. AntV aligned better with our product requirements and gave us greater flexibility for interaction design and chart behavior.

### 4. Drill-Down Analytics

Charts now support drill-down interactions. Users can click graph elements (such as bars or segments) to progressively explore deeper levels of detail, enabling better root-cause analysis and faster insight discovery.

### 5. Profiling Page Consolidation

The table-level and column-level profiling pages were merged into a single unified profiling experience, reducing navigation overhead and improving discoverability.

### 6. Dashboards Tab in Workspace

A dedicated Dashboards tab was added so users can save charts and revisit them later.

- Users can group related charts and trends in one place.
- Saved charts can be named for easier identification.
- This is especially useful for managers and decision-makers who monitor recurring indicators.

### 7. Viz Agent Chatbot Optimization

The visualization agent chatbot was optimized to improve both chart generation and response quality when answering analytical questions.

### 8. Landing Page Revamp

The landing page was completely redesigned to present a more polished, professional product identity. It now communicates core capabilities more clearly and guides potential users on access and onboarding.

### 9. Strategy Tab for KPI Monitoring

An advanced Strategy tab was introduced in the workspace to support performance management.

- Define and track KPIs, targets, and rules.
- Evaluate current metric performance against expected outcomes.
- Receive notifications when indicators are underperforming.

This feature adds a strategic decision-support layer on top of operational analytics.
